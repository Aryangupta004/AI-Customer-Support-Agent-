# Knowledge Base Documentation

The knowledge base contains four support articles that the AI agent uses to answer customer questions. Each article is stored in PostgreSQL alongside a 384-dimensional embedding generated by `all-MiniLM-L6-v2`. When a customer sends a message, the system embeds it with the same model and finds the most semantically similar articles using cosine similarity.

## Articles

### 1. How to Reset Your Password

**Category:** Account Management

Covers the full password reset flow — using the "Forgot Password" link, password requirements (12+ characters, mixed case, special characters), changing a password while logged in, and common issues like expired reset links or missing emails. Includes contact information for further support.

**Matches queries like:** "I forgot my password", "Can't log in", "How do I change my password?"

---

### 2. Billing, Invoices & Payment Methods

**Category:** Billing & Subscription

Explains the three subscription tiers (Free, Pro, Enterprise), how to add or update payment methods, and how to view invoices. Also covers what happens when a payment fails, how to dispute a charge, the 30-day refund policy, and how to cancel a subscription.

**Matches queries like:** "Why was I charged?", "How do I update my payment method?", "I want a refund"

---

### 3. API Integration & Developer Guide

**Category:** Technical Documentation

Describes the REST API, including authentication (Bearer token), available endpoints (auth, users, projects, data), request/response formats, error codes, rate limits (10,000 requests/hour), and webhook configuration. Includes troubleshooting for common issues like 401 Unauthorized and 429 Too Many Requests.

**Matches queries like:** "How do I use your API?", "What's the rate limit?", "API returns 401"

---

### 4. General Troubleshooting & Common Issues

**Category:** Technical Support

A broad troubleshooting guide covering slow performance, page timeouts, password reset link failures, account lockouts, 2FA issues, CSV import errors, connectivity problems, and server errors (502/503). Includes a browser compatibility matrix and a general diagnostic checklist.

**Matches queries like:** "Your site is slow", "I'm getting an error", "The app crashed", "Can't connect"

## How Retrieval Works

1. The user's message is embedded into a 384-dimensional vector.
2. Cosine similarity is computed against every KB article's stored embedding.
3. Articles scoring above 0.5 are considered relevant.
4. The top results (up to 3) are passed into the LLM prompt as context.

This means the agent answers using semantic meaning, not keyword matching. A question like "I can't get into my account" will correctly match the password reset article even though it doesn't contain the word "password."

## Extending the Knowledge Base

To add a new article:

1. Write the content (aim for 400+ words with clear structure).
2. Add it to the seed data script with a title and category.
3. The seed script will automatically generate the embedding and store it.
4. Re-run the seed script to load it into the database.
